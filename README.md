# Glasses Overlaying Model

This project uses OpenCV, MediaPipe, and NumPy to overlay a 3D model on a live webcam feed, specifically focusing on face landmarks. The 3D model is projected onto the face based on real-time facial landmarks.

## Requirements
- Python 3.x
- OpenCV (`pip install opencv-python`)
- MediaPipe (`pip install mediapipe`)
- NumPy (`pip install numpy`)
